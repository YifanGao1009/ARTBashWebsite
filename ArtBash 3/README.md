# ArtBash 2027 / 30th Anniversary

基于原网站、用户海报和数字花朵原图修改的静态网站，未推送 GitHub。

## 本地预览

在此文件夹运行 `python3 -m http.server 4173`，打开 http://localhost:4173/ 。

## 页面与交互

- 动画结束后，ART / BASH 以低透明度留在花朵后方；背景加入淡粉色监控小窗、目标框、连线与定位十字，装饰不拦截点击。
- 原花朵盛开动画保留，6.5 秒开始扫描转换，9.2 秒显示数字花朵与六个追踪框。
- 左上角为 30TH ANNIVERSARY；粉色粒子、无黑底数字花朵及照片对位窗口保留。
- 项目只在首屏呈现一次。点击六个框，弹窗显示项目名、类别、截止日期、完整介绍与提交要求。
- 六项信息保存在首屏的 opportunity-data 模板中；删除下方重复列表、第二张花朵索引及其搜索排序逻辑。
- 点击弹窗关闭按钮、外部或 Esc 关闭。手机弹窗限制在屏幕内；减少动画偏好直接显示最终状态。
- 向下浏览进入展览与地点信息；Open calls 返回首屏。旧项目锚点仍可打开对应弹窗。
- 六个框及编号严格遵循海报顺序。

## 文件

- index.html：页面及六个项目的唯一信息源。
- tracking.js：框定位、信息弹窗、原锚点与粉色粒子。
- photo-registration.js：照片与数字花朵的统一坐标配准及窗口采样。
- bloom.js：盛开、扫描与转换动画。
- search.css：海报风格及后续调整；style.css：原首屏基础样式。
- digital-flower.png：用户提供的原始数字花朵。

部署时将本文件夹内容复制到 GitHub 仓库的 ArtBash 3/。

背景动态：按用户提供的监控美学参考改成固定机位小窗，展示花朵局部的灰阶画面、扫描线、噪点、CAM 编号与运行计时。连线连接到花朵对应位置；目标框以停顿、跳切、重新锁定的方式更新，不进行平滑漂浮。手机保留两个小窗。六个可点击信息框保持稳定；离屏暂停，减少动画偏好使用静态画面。surveillance.js 管理此背景效果。

监控窗下的小标记分别采用断角框、偏心多边形和节点折线，数量、大小及排列错落，保留分段更新节奏。

弹窗方向：按信息框相对花朵的位置向外展开，左侧框向左、右侧框向右。侧边空间不足时先缩窄弹窗，极窄屏幕在同侧对齐并上下放置，不翻转到另一侧。
